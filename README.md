# Video Saver Pro

Preciso de uma aplicação web para copiar e colar URL de vídeos do Instagram , Facebook, YouTube, printrest, @connector:tiktok:"TikTok" e demais fontes e faça um download para  o dispositivo local, sendo que o usuário pode escolher o melhor formato e a qualidade de vídeo .  Tem que haver também a opção de extrair somente áudio. O usuário poderá escolher o nome.
